Project Title: Soft-Gadgets-Mid-year-Sales
Analyzing the first 6 months of the sales of gadgets to know our orofit killers and makers
Tools: Excel for cleaning, PowerBi for visuals
Process: The data set was extracted from kaggle and uploaded on Microsoft excel sheet for cleaning. Data visualization was done on PowerBi.
Key findings: The profit made was $254.93k
Smartphones had the highest revenue while tablets has the lowest.
Asia tops the chart in revenue but North America is more profitable in margin while Europe lags behind in both areas.
